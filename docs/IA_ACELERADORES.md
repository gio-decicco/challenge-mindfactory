En este proyecto fueron utilizadas dos herramientas de IA: ChatGPT y Cursor

Se utlizó en este proyecto ChatGPT para la resolución de dudas generales, simples. Como un ayuda memoria para instalación de nuevos paquetes y resolución de pequeñas dudas. También para la consulta de alternativas en cuanto a escalabilidad, rendimiento de código, etc.

Cursor es el editor de código que uso desde mi anterior trabajo. Facilita tareas repetitivas, tales como la creación de tests unitarios y de integración.
En lo personal, a cursor no me gusta darle rienda suelta porque suele acumular muchas funcionalidades en pocos archivos de código y es muy difícil que entienda la escalabilidad y varios principios SOLID. En casos generales como en este caso lo uso para resolver errores comunes cuando ya tengo las cosas listas, para iterar sobre errores y hacer tests. El código que genera nunca se aplica directamente ya que lo reviso a todo.
